## Deploy steps

1. Upload `uploads/properties/cc-*` and `uploads/regions/*.jpg` to the server.
2. Run `database/migrations_parent_company_properties.sql` in phpMyAdmin / MySQL.
3. Re-running the migration must still yield **25** rows with `source_name='century_communities'`.
4. Walk the verification checklist in `database/parent_company_verification_checklist.md`.
